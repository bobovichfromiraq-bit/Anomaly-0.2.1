# Zone Anomalies 0.4.0
Minecraft **1.21.1**, **NeoForge 21.1.x**, Java 21. Аномалии в духе S.T.A.L.K.E.R. 2: объёмные 3D-эффекты, искажение мира, новые механики.

## Аномалии
| | Визуал | Механика |
|---|---|---|
| **Гравитационная** | 4 вложенные воронки со спиральным рельефом, ударные кольца, обломки (камни и мини-блоки земли, на которой она стоит), искажение пространства по форме воронки | Затягивает, поднимает по спирали, разрывает. Притягивает и швыряет вверх предметы, опыт, стрелы, падающие блоки. Дрожь камеры рядом. |
| **Электрическая** | Плазменный шар, фрактальные молнии во всех направлениях с ответвлениями (обрываются на поверхностях), блик-звезда, выжженное пятно | Урон 3 сердца + замедление + слепота 5 с. Каждый разряд даёт сигнал редстоуна 15 на 0,6 с (ловушки!). Шар «оживляется» при приближении. |
| **Кислотная** | Цельный бульк-блок, сливающийся в лужу, слои ядовитой дымки над поверхностью, пар, лопающиеся пузыри, зелёный дымок | Яд + замедление + иссушение, броня разъедается. Ядовитый воздух над лужей: ~3 с дыхания — тошнота. Зелёный туман вблизи. |

## Совместимость с Iris / Oculus
Пока включён шейдерпак, пост-обработка (искажение мира и туман) **автоматически отключается** — иначе она испортила бы кадр.
Все 3D-эффекты (рендер блок-сущностей на ванильных рендер-типах), частицы и звуки работают и с шейдерпаками.
Принудительно включить искажение: `distortionWithShaderPacks = true` в `config/anomalies-client.toml`.

## Сборка
Текстуры, звуки и меши в репозиторий не входят — их генерируют `tools/build_meshes.py` и `tools/generate_assets.py`
(в CI автоматически; локально: `pip install numpy pillow scipy` + ffmpeg). Файл сборки: `ci/build.yml`
(положить в корень репозитория как `.github/workflows/build.yml`).

## Настройки
`config/anomalies-common.toml`: `affectCreativePlayers`, `gravityPullRadius`, `gravityLiftTicks`, `electricDamage`,
`effectDurationTicks`, `detectorRange`, `acidHazeSickness`, `electricRedstoneSignal`.
`config/anomalies-client.toml`: `worldDistortion`, `distortionStrength`, `distortionWithShaderPacks`, `cameraShake`, `toxicFog`.
